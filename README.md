# portofolioviolin

Personal portfolio of Violin Mulya. Static Next.js site in English and Indonesian.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui (Radix), Framer Motion, next-intl. Deployed on Vercel.

## Development

```bash
npm install
npm run dev
npm run lint
npx tsc --noEmit
npm run build
```
